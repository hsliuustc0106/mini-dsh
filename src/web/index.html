Plugins

Installed plugins show their status, dependencies, supported settings, and tool permissions. Unknown tools stay denied. Installing a package does not make an unsupported service available.

    Install a plugin

    Enter an npm package or HTTPS GitHub repository URL. Installation can run package code; install only plugins you trust. Compatible plugins activate without a restart.
